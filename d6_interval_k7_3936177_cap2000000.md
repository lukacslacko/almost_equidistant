## Commit gate, launch, and resume

The runner refuses a production launch unless all tracked files are clean and
the exact runner, dependency, manifest, and manifest-verification working
files equal their blobs at `HEAD`.  Untracked research files are permitted but
recorded in the hashed Git provenance.  The wrapper also requires an explicit
sleep-prevention command.

After committing this five-file package, launch with

```text
caffeinate -dimsu python3 run_d6_interval_k7_3936177.py \
  --checkpoint-dir .runs/d6_interval_k7_3936177_cap2000000 \
  --output .runs/d6_interval_k7_3936177_cap2000000.json \
  --decisions .runs/d6_interval_k7_3936177_cap2000000.tsv \
  --outer-launch-command \
  'caffeinate -dimsu python3 run_d6_interval_k7_3936177.py --checkpoint-dir .runs/d6_interval_k7_3936177_cap2000000 --output .runs/d6_interval_k7_3936177_cap2000000.json --decisions .runs/d6_interval_k7_3936177_cap2000000.tsv'
```

The same command resumes the matching checkpoint directory.  Use
`--retry-infra-errors` only if a completed checkpoint explicitly records
`INFRA_ERROR`; this affects retry scheduling, not the hashed mathematical
configuration.  Never edit a checkpoint or log in place.

The producer runs the exact 24-slice positive control (a realizable K7 plus
twelve generic points on its common-unit circle) and negative control (a K8,
impossible in `R6`) before the target.

## Independent verification

After the run completes, hash the immutable report and run

```text
python3 verify_d6_interval_k7_3936177.py \
  --report .runs/d6_interval_k7_3936177_cap2000000.json \
  --expected-report-sha256 <REPORT_SHA256> \
  --output /tmp/d6_interval_k7_3936177_cap2000000_verification.json
```

The checker imports neither launch wrapper.  It independently rebuilds all
644 v6 records, selects exactly index `3936177` by corpus index, audits the
one-element selection hash and K7 class, checks all committed source/input
blobs and the tracked-clean launch boundary, checks the campaign, result,
session, progress, checkpoint, and decision TSV structures, replays all 48
control slices, and replays all 24 winning target slices.  It returns `PASS`
only if the single graph is `KILLED`.  Do not use `--no-replay` for an official
verification.

## Trust boundary

The only prospective rejection mechanism is the existing outward-rounded
interval kernel.  It assumes correctly rounded IEEE-754 binary64 basic
operations and square root, expanding every interval endpoint with
`nextafter`.  It assumes macOS `libm` cosine endpoint error of at most eight
ulps; both directions receive eight `nextafter` padding steps and all interior
extrema are included.  Candidate nonedges remain unconstrained and may also
have unit distance.  Only a complete `KILLED` tiling is a conclusion;
`ABORT`, `UNRESOLVED`, and `INFRA_ERROR` are not rejections.

The v6 selection root separately accounts for 264 exact algebra/graph
rejections and three independently checked interval increments; no
non-`KILLED` interval status was used in constructing it.
