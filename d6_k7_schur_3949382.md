required K7 seed of graph `3949382`.  The proof uses strict positivity in a

probe are not yet a production residue update.  Promotion should freeze the
source boundary, add an independent report checker, and union the resulting
one-graph rejection with the other certified K7 increments.

## Schur equations

The normalized Gram matrix has rank at most seven.  The clique principal
block is

```text
M = J + diag(1/a,1/b,1/c,1/d,1/e,1/f,1/g)
```

with

```text
a,b,c,d,e,f,g > 0.
```

It is positive definite and saturates the rank, so its Schur complement is
zero.  Put

```text
T = 1+a+b+c+d+e+f+g.
```

For a basis-neighbour set `U`, write `w(U)` for the sum of its variables.
Sherman--Morrison gives, for every remainder pair with exact target
`epsilon in {0,1}`,

```text
T w(U intersect V) - w(U)w(V) - epsilon T = 0.
```

The five masks are

```text
A = {a,b,e,g}
B = {a,b,c,d,f}
C = {b,f,g}
D = {b,c,e,g}
E = {b,d,e,g}.
```

Subtracting the equal-left-part equations for `AC`, `CD`, and `CE` gives

```text
(a-c)(b+f+g)=0,
(c-d)(b+f+g)=0.
```

Strict positivity therefore forces

```text
a=c=d=:t>0.
```

All ten pair equations then reduce to four:

```text
T = 1+3t+b+e+f+g
P = t+b+e+g
Q = 3t+b+f
R = b+f+g

E0 = (t+b)T       - P Q = 0
E1 = (P-t-1)T     - P^2 = 0
E2 = (b+g-1)T     - P R = 0
E3 = (b+f-1)T     - Q R = 0.
```

## Short exact elimination

Let

```text
h=t+b,       L=2t+f.
```

Then `Q=h+L` and `T=P+L+1`.  Equation `E0=0` becomes

```text
h(L+1)-PL=0.
```

Since `L>0`,

```text
P = h(L+1)/L.
```

Writing `u=b+g-1`, equation `E2=0` now reduces, after cancelling the positive
factor `(L+1)/L`, to

```text
uL=h(f+1).
```

Using `P=h+e+g` gives

```text
e+g = h/L,
g   = 1-b+h(f+1)/L,
e   = h/L-g.
```

Substitution in `E1` yields the exact factorization

```text
E1 = -(L+1)/L * (t^2+2t+f-b(t+f)).
```

All cancelled factors are positive, so

```text
b = (t^2+2t+f)/(t+f),
e = (t+1)(t-f)/(t+f),
g = -(t+1)(t-f-1)/(t+f).
```

Finally,

```text
E3 = (2t+f+1)^2/(t+f)^2 * (t^2-tf-t-f).
```

Thus `E3=0` forces

```text
t(t-f-1)=f>0,
```

and therefore `t-f-1>0`.  But the displayed formula for `g`, with positive
numerator factors and denominator, now gives `g<0`, contradicting the required
strict positivity `g>0`.

No equality solution lies in the strict positive orthant.  The point

```text
(a,b,c,d,e,f,g)=(1,3,1,1,2,0,0)
```

does satisfy all ten equations, which explains the numerical approach to the
boundary and serves as a control that strict positivity is essential.

## Independent algebra cross-check

The test suite uses a second elimination rather than repeating the probe's
steps.  It verifies coefficientwise the identities

```text
(f+2t+1) A0 = (f+t)E0 + (f+2t)E1,

(b+t-1) B0 = (b-2)(E0+E1) + t(E2+E3),
```

where

```text
A0 = b(f+t)-f-t^2-2t,
B0 = bf+bt+b-ft-2f-gt-4t-2.
```

The first identity gives `b>1`, so the factor `b+t-1` in the second is
strictly positive.  Solving `A0=B0=E0=0` and substituting into `E2,E3` gives
opposite multiples of the same final factor.  It independently obtains

```text
f=t(t-1)/(t+1),
g=-(t-1)(t+1)/(2t^2).
```

Strict `f>0` forces `t>1`, hence again `g<0`.
